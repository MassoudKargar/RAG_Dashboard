# Sample benchmark data

The files in this directory are **sample data for the `demo` benchmark mode
only** (also used by automated tests). They are illustrative values — including
values that resemble real benchmark results — and must never be treated as
live production metrics. Production runs come from the RAG service or a
configured upstream API.

- `benchmark-runs.sample.json` — demo benchmark runs (labels clearly visible
  in the UI when demo mode is active).
